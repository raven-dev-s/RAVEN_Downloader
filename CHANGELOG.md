# Changelog

Each release publishes the notes under its version heading to OpenStore. Add
a section for the version in `CMakeLists.txt` before pushing a release. Keep
the notes short and written for people using the app.

## 4.3.8

- The lock screen shows how many videos you downloaded today

## 4.3.2

- The Library follows the theme and no longer goes blank after you change it
- The app list in "Save as…" no longer starts underneath the title bar
- Deleting a file from the Library asks first
- Videos without a thumbnail show a tile that suits the dark theme

## 4.3.1

- Downloads are kept in a Library: swipe up from the bottom edge to see them
- "Save as…" sends a file to Music, Videos, or another app, and now closes properly
- One progress bar for video and audio together, with automatic retries when the connection drops
- "Audio only" comes first in the quality list
- The link field is easier to spot and ready to type in when the app opens
- Smaller download and install size

## 4.3.0

- Ubuntu Touch 20.04 is supported again, alongside 24.04
- Redesigned link entry, list, Settings, and About pages
- Audio-only downloads
- Settings apply without restarting the app
